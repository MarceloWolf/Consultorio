# CapacitacionFrontend
# By Lucas Diez and Santiago Rubini

Este repositorio contiene la parte del frontend de la aplicacion de consultorio medico.


## Como ingresar
Para poder ingresar primero deben realizar los pasos explicados en el proyecto del backend
```
https://gitlab.certant.com/ldiez/capacitacionbackend
```
Una vez realizado pueden correr este proyecto ingresando a la terminal del VSCode ingresando el siguiente comando:

```
'npm start' o 'ng s -o' (Para abrir la pestaña automaticamente)
```

Luego una vez corriendo la aplicacion, pueden ingresar al link:
```
http://localhost:4200/
```
Y ahi ingresaran el usuario y contraseña del admin que crearon en el swagger del proyecto del backend
